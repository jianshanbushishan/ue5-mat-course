# UE5 材质工坊 · 零基础交互式学习指南 (UE 5.8 · Substrate Ready)

一款对标现代交互式学习工作台设计、专为 **纯零基础读者** 打造的 **Unreal Engine 5.8 材质系统** 互动式可视化教程应用。

## 核心亮点

- **11 个模块 · 41 节课（共 205 个步骤）**：
  - 从光与人眼显色、CPU/GPU 并行分工、三角形与法线“小牙签”、四大空间参考系等底层背景出发；
  - 层层深入 `0~1` 归一化与向量、算术五件套、UV 橘子皮展开、`sRGB / Linear` 色彩空间、纹理位深与 `ORM` 通道打包、纹理滤波与 `Mipmap` 摩尔纹救星、`BC1~BC7` 显存块压缩与法线勾股重建；
  - 专项深挖 **漫反射、镜面反射与环境倒影、环境光遮蔽（AO）、阴影系统（含 VSM 虚拟阴影与彩玻投影）**、PBR 微表面/菲涅尔/金属度铁律与 **UE 5.8 材质创建、转换与 `Substrate` 层板工作流**；
  - 完整拆解 **水（Single Layer Water）、玻璃（前向表面高光与折射）、雾（体积雾粒子与半透明雾片）、烧蚀溶解、科幻能量护盾、世界空间滚石积雪、三平面投射、SSS 玉石透光、双层车漆清漆、冰层内裂纹视差与 UE 5.8 原生卡通渲染**。
- **40 节概念实验与 1 节综合练习**：像素显微镜、双向同步 UV 画笔、16 级灰阶盲测、集装箱通道打包、跑道掠射角滤波拉帘、`4×4` 纹素块放大镜、暗室黑银球实验、头顶一线天 AO 张角仪、阶梯海湾水深吸收剖面、水晶杯折射、360° 滚石落雪等，纯用于直观体验与顿悟，全程自由跳转无锁卡。
- **配套三大实战工作台**：
  - **🩺 实战排错诊所**：12 个高频材质翻车现场，支持一键「看翻车现象 ↔ 修复预览」对比。
  - **🧪 材质综合实验室**：PBR / Substrate 多环境教学预览、支持上传图片的块压缩示意与纹理数据量估算、迷你节点连线游乐场。
  - **📋 案头速查手册**：4 张生产级黄金配置对照表 + 10 项母材质提交自检清单。

第 11.1 课提供三张可下载的 PNG。从空白工程创建检验板，完成母材质、实例、关卡复查和 Platform Stats 记录。

## 本地运行与构建

```bash
# 安装依赖
npm install

# 启动本地开发服务器
npm run dev

# 生产环境构建（可直接部署至 Vercel / Netlify / 静态托管）
npm run build
```
